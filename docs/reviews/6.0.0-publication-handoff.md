## Release-note extraction correction

The local publication rehearsal exposed a pre-existing Bash 3.2 performance
defect: globally removing whitespace to test whether notes were empty consumed
minutes of CPU on the full 6.0 body. Both the real section and a large Unicode
fixture timed out at five seconds, while the short/missing/empty controls
passed. A non-whitespace regex check avoids rewriting the body and preserves
the extracted content. Three subprocess regressions cover both large bodies
and the controls in the PR, exhaustive, and release lanes. This extraction
fix and its CI regression wiring are the only executable changes in the
preparation; library behavior, performance budgets, and release policy stay
unchanged.
